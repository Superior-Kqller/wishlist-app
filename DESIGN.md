## Обзор

Основа — Airbnb: щедрый потребительский маркетплейс, где тяжесть несут фотографии, а не шрифт. Для Вишлиста это точное попадание: карточки желаний — те же «объявления» с фото, за которыми стоит живой человек, а люди и поводы важнее интерфейса вокруг них.

Страница — на 90% холст и чернила. Фирменный цвет появляется один-два раза на экран: главное действие, сердечко «хочу», точка ближайшего события. Если на экране три малиновых пятна — одно лишнее.

**Характер:** тёплый, спокойный, человеческий. Не SaaS-панель, не редакционный журнал.

## Цвет

- **Одна краска.** `primary` (#e00b41) — заливка главного действия с белой подписью. Яркий `brand` (#ff385c) — только там, где нет текста: сердечко, точка, полоса индикатора. Белый текст на #ff385c даёт 3.52:1 — поэтому текстовые кнопки на нём не делаем. Это отступление от референса ради доступности.
- **Второго фирменного цвета нет.** Выбор, активная вкладка, выбранный день — чернилами (`ink`), а не краской: чёрная заливка + белый текст, подчёркивание 2px.
- **Статусы** (`success/warning/error/info`) — только для состояния: «куплено», предупреждение, ошибка. Никогда не декор. Всегда в паре с иконкой или словом.
- **Приоритеты** — пятиступенчатая шкала, всегда с цифрой или подписью, не только цветом.
- **Фото товара** лежит на `surface-soft`-плитке с `mix-blend-mode: multiply`: белый фон магазинных снимков растворяется. В тёмной теме плитка остаётся светлой (#e8e8e8) — товар не должен тонуть.
- **Тёмная тема** — «Системная / Светлая / Тёмная» в меню аккаунта и в «Ещё»; по умолчанию системная. Холст #161616 (не чистый чёрный), карточки на ступень светлее, те же радиусы и ритм. Акцент-текст переходит на яркий `brand`.

## Типографика

Одна гарнитура — **Inter** (замена Airbnb Cereal по рекомендации референса; кириллица родная). Сериф, моноширинный для UI и декоративные начертания не используются.

Веса скромные: заголовок страницы — 28/700, и он намеренно небольшой — под ним фото и лица. Единственный громкий шаг — `stat-display` (48/700) для цифр статистики и «через N дней» у ближайшего повода.

Цифры — `tabular-nums` везде, где они сравниваются: цены, даты, счётчики.

## Раскладка

- База 4px, шаги из `spacing`. Между карточками в сетке — 16px (плотный маркетплейс), между разделами — 48–64px (воздух).
- Контент до 1280px по центру. Детальный вид — до 1080px: слева фото и описание (~64%), справа липкая карточка действий (~32%), на мобильном она становится нижней липкой панелью.
- Сетка карточек сокращает число колонок, но никогда не переупорядочивает: 1 → 2 → 3 → 4 на брейкпоинтах 744 / 1128 / 1440.

## Глубина

Одна тень — `float`. Ей пользуются: карточка при наведении, выпадающие меню, липкая карточка действий, плашки поверх фото. Всё остальное плоское: поверхности разделяются белым-на-белом, волосяными линиями и скруглением. Никаких стеклянных панелей, свечений и фоновых градиентов.

Модальное окно — `scrim` 50% (65% в тёмной) без размытия.

## Форма

Острых углов нет нигде, кроме самой сетки страницы.

| Элемент | Радиус |
|---|---|
| Кнопка, поле ввода, пункт меню | `sm` 8px |
| Карточка, фото, панель | `md` 14px |
| Диалог, нижний лист | `lg` 20px |
| Поиск, чипы, фильтры, плашки, аватары, иконки-кнопки | `full` |

## Компоненты

**Кнопки.** Высота 48px (главные) / 40px (компактные), радиус 8px, вес 500.
- `primary` — заливка `primary`, белый текст; ховер `primary-hover`. Одна на экран.
- `secondary` — холст, чернила, рамка 1px `ink`.
- `outline` — холст, рамка `hairline`, ховер `surface-soft`.
- `ghost` — без поверхности; ховер `surface-soft`.
- `link` — текст чернилами, подчёркивание на ховере; фирменный цвет только у ссылок в тексте.
- `icon-circle` — 32–40px круг, `surface-strong` или холст с рамкой.
- Нажатие меняет цвет, без сдвига и масштаба.

**Поиск.** Пилюля на холсте, рамка `hairline`, тень `float`, высота 48–56px; справа круглая кнопка-«орб» с заливкой `primary`. На мобильном — одна пилюля, по нажатию открывает полноэкранный поиск с фильтрами.

**Чипы / фильтры.** Пилюли 36px: неактивный — рамка `hairline`, активный — рамка 2px `ink` (или заливка `ink` с белым текстом для переключателей-сегментов).

**Карточка желания.** Фото 1:1 (или 4:5) со скруглением 14px, без рамки у самой карточки. Почти квадратный снимок (от 4:5 до 5:4) занимает плитку целиком; вытянутый вписывается с полями 24px, чтобы товар не обрезался. Поверх фото: плашка слева сверху (приоритет / «куплено») — белая пилюля с тенью `float`; справа сверху — круглая кнопка действий. Ниже фото 3–4 строки: название `title-md`, владелец и список `body-sm muted`, цена `body-sm` с весом 600. Ховер — фото чуть увеличивается (1.02), без тени у карточки.

**Карточка человека.** Круглый аватар 56–64px, имя `title-md`, под ним ближайший повод `body-sm muted`. Карточка — холст с рамкой `hairline`, радиус 14px, отступ 24px. Ниже — любимые цвета рядом точек (до шести, дальше «+N») и до трёх подсказок-чипов. Повод в пределах месяца — «через N дней» чернилами с точкой `brand`. Выбранная карточка — рамка 2px `ink`.

**Навигация.** Верхняя панель 72–80px, холст, линия `hairline` снизу. Слева знак, по центру разделы (текст `nav-link` 16/600; активный — чернила + подчёркивание 2px, неактивные — `muted`), справа поиск-иконка и меню аккаунта (пилюля с аватаром). На мобильном — нижняя панель разделов: иконка + подпись 12px, активная — чернилами.

**Поля.** Высота 48–56px, холст, рамка `hairline`, радиус 8px, подпись сверху `caption muted`. Фокус — рамка 2px `ink`, без свечения. Ошибка — рамка и текст `error`.

**Календарь.** Дни — круги 40px; выбранный — заливка `ink`, белая цифра; сегодня — рамка `ink`; день с поводом — точка `brand` под цифрой.

**Диалоги.** Холст, радиус 20px, отступ 24px, заголовок `display-sm`, действия справа внизу. На мобильном — нижний лист во всю ширину с радиусом 20px сверху.

**Пустые состояния.** Иконка-линия 32px `muted`, заголовок `title-md`, одна строка пояснения, одна кнопка. Без иллюстраций и свечений.

## Движение

Короткое и функциональное: 140ms (цвет), 220ms (появление поверхностей), 420ms (раскрытие листов). Кривая `cubic-bezier(0.16, 1, 0.3, 1)`. При `prefers-reduced-motion` остаются только смены цвета и прозрачности.

Эффекты из kinetics.colorion.co — с исходными параметрами, каждый на своём месте:

| Эффект | Где | Параметры |
|---|---|---|
| Tab Pill Glide | все сегменты, полоска раздела в шапке | 400ms, `cubic-bezier(0.65, 0, 0.35, 1)`, сдвиг через `transform` |
| Hover Effect (21st.dev) | сетка людей на «Подарочных профилях» | одна подложка `surface-soft` переезжает к карточке под курсором (`layoutId`, 400ms `expo`), появление 150ms, уход 150ms с задержкой 200ms; только мышь |
| Odometer Count-up | итоги и счётчики «Статистики», полосы приоритетов растут вместе с ними | от нуля до значения за 1400ms, кривая `1 − (1 − p)³`, старт при 50% элемента в кадре, `tabular-nums` |
| Stagger Entrance | сетка желаний, сетка людей, блоки панели профиля при смене человека | 14px, 450ms `expo`, шаг 90ms, не больше 8 шагов |
| Checkbox Draw | флажки | штрих галочки 320ms `expo` |
| Badge Counter | счётчик фильтров | pop 1.4× → 1, 300ms `expo` (без перелёта) |
| Error Shake | поля входа при ошибке | 450ms затухающее покачивание |
| Icon Morph Swap | переключатель вида на телефоне | 300ms: blur 6px, `scale(0.7) rotate(-20deg)` |
| Underline Draw | ссылки (`link`) | подчёркивание 400ms слева направо |
| Success Check | «Уже куплено» в момент отметки | кольцо 500ms, затем галочка 300ms |
| Accordion Spring | сворачиваемые блоки: подарочные предпочтения, история календаря; шеврон «Все изменения» | тело 450ms `expo` через `grid-template-rows`, шеврон 350ms `cubic-bezier(0.34, 1.56, 0.64, 1)` |
| Submit States | кнопки отправки форм (`Button status`) | точки 0.6s, шаг 0.12s; галочка 0.4s пружиной — только там, где форма остаётся на экране |
| Skeleton to Content | статистика, лента календаря после скелетона | 8px, 420ms `expo` (`data-reveal`) |
| Choice Chips | чипы анкеты предпочтений | pop 1.12, 300ms пружиной — единственное исключение из «нажатие без масштаба» |
| Swatch Picker | цветной образец в отмеченном чипе | 1.2, 500ms пружиной, кольцо 2px своего цвета |
| Blur Fade (21st.dev) | фото карточки желания при загрузке | размытие 6px → 0, 400ms `ease-out`, задержка 40ms, без сдвига |
| Undo Snackbar | удаление одного желания: тост «Желание удалено · Отменить» | выезд 0.4s пружиной, полоса тает 3s линейно; запрос DELETE — по истечении |

Нижний лист на телефоне смахивается вниз (Base UI Drawer): 500ms на появление, 250ms на уход, `cubic-bezier(0.23, 1, 0.32, 1)`. Сдвиг — через `transform`, не `left`/`top` (HeroUI → Animation → Performance).

## Делать / не делать

- Делать: давать фото и лицам занимать место; держать один малиновый акцент на экран; выбор показывать чернилами.
- Не делать: градиенты, стекло, свечения, цветные тени; второй фирменный цвет; белый текст на ярком `brand`; жирнее 700; сериф.
- Не обещать формулировками защиту от двойных покупок (см. PRODUCT.md).
